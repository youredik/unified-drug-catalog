# Демонстрационные выгрузки

Данные **вымышленные**. Торговые наименования (`Acmeflex`, `Northaid`)
и производители (`Acme Pharma`, `Northwind Health`) не существуют; совпадение
с настоящими было бы случайным.

Штрихкоды выданы из префикса GS1 `29` — диапазона **restricted distribution**,
который никогда не назначается реальным розничным товарам. Коллизия с настоящим
товаром исключена по построению, а контрольная цифра во всех трёх намеренно
не сходится: именно на этом проверяется правило «невалидный идентификатор
понижается в роли, а не отбрасывается».

## Что здесь спрятано

| Ловушка | Где |
|---|---|
| Контрольная цифра не сходится | все три штрихкода |
| Дозировка тремя способами | `strength_mg: 200` · `"200 mg"` · `{amount, units}` |
| Страна тремя способами | `GB` · `United Kingdom` · `UK` (не валидный ISO 3166) |
| Дата тремя форматами | `2023-01-15` · `15.01.2023` · `2023/01/15` |
| Производитель тремя уровнями подробности | `Acme Pharma` · `… Ltd.` · `… Healthcare` |
| Рецептурность тремя способами | `false` · `"false"` · `"no"` |
| Уточнение формы в наименовании, а не в структурном поле | `Film-coated Tabs` при `kind: "tabs"` |
| Разная дозировка — **не** дубликат | Acmeflex 200 мг против 400 мг |
| Тот же препарат, другой бренд — **не** дубликат | Acmeflex против Northaid |

Шесть записей трёх сетей должны дать **три** позиции каталога, а не одну и не шесть.
